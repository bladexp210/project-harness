# Task boilerplate

Filled task skeletons promoted from successful runs. Start from
[[new-task]] in `_templates/`; copy a promoted file here when a task type
recurs (e.g. "add CRUD endpoint", "migration with expand-contract").

This harness seeds specs in `../specs/` instead — see
[[harness-task-spec-example]].
