# Publish later

GitHub renders this README and ordinary markdown links. It does not render Obsidian wiki-links. A static site (for example Quartz on GitHub Pages) is optional.

This public repository does **not** include:

- A live site URL
- A personal access token or webhook
- Scripts that sync into a private site repo
- A workflow that dispatches a rebuild to another repository

When you want a site, create a separate repository, copy the markdown yourself, and keep tokens in that repo's secret store. Do not commit them here.
