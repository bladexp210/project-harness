# Decommission records

One record per **whole-product sunset**. Feature-level removal uses Ch. 07
*retire* flow — not this folder.

## How to create

1. Copy `_templates/decommission-record.md` →
   `decommission/<product>-YYYY-MM-DD.md`
2. Start the record when kill criteria are met — before public notice
3. Update through each Gate F step until archive is complete
4. Link the final post-mortem in `06-learn/post-mortems/`

## Examples in this repo

| Record | Type |
| :---- | :---- |
| [example-harness-repo-sunset](example-harness-repo-sunset.md) | Harness-meta — winding down this book repo |
| [example-fictional-saas-sunset](example-fictional-saas-sunset.md) | Fictional SaaS — **NoteShelf** training artifact |

Replace both with your product's record when you sunset for real.
