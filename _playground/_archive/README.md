# _playground/_archive/

Exploration memory — experiments archived after **4 days** without promotion
(see [[../README|playground rules]]). Folders are moved here as
`YYYYMMDD-<experiment-name>/` by `scripts/playground_archive.py`.

Review before deleting anything from git history; archived work may contain
ideas worth re-promoting later.
