# Problem

Acme employees ask the same paid-time-off questions every week. The answers live in three places that disagree:

- An HR handbook PDF, updated twice a year
- A pinned chat message from last quarter
- A tooltip in the HR system that still quotes an older rule

People guess, or they interrupt HR. HR cannot see which questions the documents failed to answer.

**Outcome we want:** an employee can ask a PTO question and get the current rule, the clause it came from, or a clear refusal when the approved text does not cover the question.
